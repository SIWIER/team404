# 🔧 防丢标签 · 从零组装手册（跟着做就行）

> 适用材料清单（淘宝件）：ESP32-C3 SuperMini 开发板、有源蜂鸣器 5V、TP4056 Type-C 充电板（带保护）、3.7V 锂电池 502030、拨动开关 SS-12D00、杜邦线、热缩管、3D 打印外壳（STL 在 `hardware/`）。

---

## 阶段 0：软件环境（一次性，约 20 分钟，先做这个）

1. 下载安装 **Arduino IDE**（arduino.cc，免费）
2. 文件 → 首选项 → "附加开发板管理器网址"粘贴：
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
3. 工具 → 开发板 → 开发板管理器 → 搜索 `esp32` → 安装（by Espressif）
4. 准备一条**能传数据的** USB-C 线（很多充电线只能充电，连不上串口）

## 阶段 1：面包板验证（先不焊，插线试）

**接线表：**

| ESP32-C3 SuperMini | 接 |
|---|---|
| 5V 引脚 | 面包板正极轨 |
| GND | 面包板负极轨 |
| GPIO5 | 蜂鸣器 **+**（有源蜂鸣器上有"+"或长脚标识） |
| 蜂鸣器 **-** | GND 轨 |
| GPIO4 | 按钮一脚（可选） |
| 按钮另一脚 | GND 轨（可选） |

**烧录步骤：**
1. 打开 `hardware/firmware/tag_firmware/tag_firmware.ino`
2. 工具 → 开发板 → **ESP32C3 Dev Module**；工具 → 端口 → 选新出现的 COM 口
3. 点"上传"（→）
4. 打开串口监视器（右上角放大镜图标），波特率选 **115200**

**验收标准：** 上电后蜂鸣器**短哔三声** + 串口打印 "WiFi 已连接，IP: ..."
- 如果串口一直打印"...."→ WiFi 连不上：确认是 **2.4G WiFi**（ESP32-C3 不支持 5G），密码正确
- 如果完全不响 → 检查蜂鸣器方向/接线；把蜂鸣器直接插 5V 和 GND 试一下响不响（有源蜂鸣器通电就该响）

## 阶段 2：接入我们的系统（联调，手机一点它就响）

1. 小程序/网页 → 硬件设备页 →「＋ 注册设备」→ 类型选"防丢标签" → 得到设备 ID（如 `dev-xxxx`）
2. 修改固件顶部配置：
   - `WIFI_SSID / WIFI_PASS` = 你家 2.4G WiFi
   - `SERVER_HOST` = 电脑局域网 IP（cmd 输入 `ipconfig` 查 IPv4）
   - `DEVICE_ID` = 第 1 步注册得到的 ID
   - `TOKEN` = 电脑上执行（输出那串就是）：
     `node -e "fetch('http://127.0.0.1:8081/api/auth/login',{method:'POST',headers:{'Content-Type':'application/json'},body:JSON.stringify({username:'xiaoming',password:'123456',remember:true})}).then(r=>r.json()).then(d=>console.log(d.token))"`
3. 重新上传固件 → 串口监视器应看到 `📡 心跳上报: HTTP 200`
4. 手机上点该设备的「🔔 蜂鸣」→ 串口打印 `📨 收到指令...开始蜂鸣` → **标签响了！** → 打印 `✅ ack 回报: HTTP 200`

## 阶段 3：焊接组装（告别面包板）

焊接顺序（先易后难）：
1. 电池线：锂电池正极（红）→ **开关一脚**；开关另一脚 → TP4056 的 **B+**；电池负极（黑）→ TP4056 的 **B-**
   （TP4056 板上有 B+/B-/OUT+/OUT- 丝印）
2. TP4056 的 **OUT+** → ESP32 的 **5V** 引脚；**OUT-** → ESP32 的 **GND**
3. 蜂鸣器：+ 脚 → GPIO5，- 脚 → GND（可以焊在 TP4056 的 OUT- 上）
4. 按钮（可选）：一脚 → GPIO4，另一脚 → GND
5. 所有裸露焊点套热缩管

**安全三查：**
- 焊电池前，开关必须处于"关"
- 通电前用万用表量：OUT+ 和 OUT- 之间应为 3.7~4.2V
- 电池正负极绝不反接、绝不短路

## 阶段 4：装进 3D 外壳

1. 打印 `hardware/tag_case_base.stl` + `tag_case_lid.stl`（层高 0.2、PLA、无需支撑）
2. 电池放左舱（底部），TP4056 放右舱，**USB-C 口对准右壁开孔**
3. ESP32 扣上四根固定柱（USB-C 朝**左壁开孔**），蜂鸣器塞进盖子圆环（热熔胶点一点）
4. 开关卡进前壁槽，理好线，扣上盖子
5. 挂绳穿进钥匙环挂耳 → 挂眼镜盒上 → 开机 → 手机测试蜂鸣

## 常见问题

| 现象 | 排查 |
|---|---|
| 串口全是"...." | 2.4G WiFi？SSID/密码？离路由器近点 |
| 串口没显示任何东西 | 波特率选 115200；USB 数据线；重插板子 |
| 上传报错找不到板子 | 开发板选 ESP32C3 Dev Module；端口选对；按住板子 BOOT 键再点上传 |
| 心跳 401 | TOKEN 过期，重新获取；或没填 TOKEN |
| 心跳 404 | DEVICE_ID 与系统里注册的不一致 |
| 手机点了不响 | 看串口：没收到指令=轮询没通；收到但不响=蜂鸣器坏/接反 |
| 充电时板子发热 | 立刻断电检查接线，先量电压再通电 |

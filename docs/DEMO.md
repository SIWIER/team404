# 🎬 演示脚本（约 10 分钟）

> ⚠️ **产品已转型**（2026-08）：本脚本写于「找眼镜」时期，整体仍可用但口径已旧。
> 推荐演示口径：**物品数字化存放系统**——登录 → 物品管理（拍照录入+自动识别名）→
> 找物品引导（四策略：问答回忆/文字检索/拍照找同款/描述找物品）→ 存放统计（户型存放热力）→
> 户型图配置（目录/房间/内部模块）→ 硬件页。本文档待按新口径整体重写。

> 演示前准备：双击 `start.bat`（或 `node server.js`）→ 运行 `node scripts/smoke.js` 自检全绿 → 浏览器打开 http://localhost:8081

## 开场（30 秒）
"这是帮在家里没戴眼镜的人找回眼镜的助手。没戴眼镜看不清，反而最难找眼镜——它用问答推理 + 个人数据 + 硬件定位来帮你。"

## 第 1 幕：登录与个性化（1.5 分钟）
1. 用 `xiaoming / 123456` 登录（点"记住我"）
2. 首页展示「小明的小镜助手」画像卡：生活习惯、常用地点、**🏠 家庭户型**（5 个房间）
3. 说："每个人的数据完全隔离"——退出，用 `xiaohong / 123456` 登录，对比画像差异（小红的户型有玄关）

## 第 2 幕：引导推理（核心，3 分钟）
1. 换回 xiaoming → 点「🔍 引导推理找眼镜」
2. 场景设定："假设我昨晚洗了澡，今早发现眼镜不见了"
3. 依次回答（展示**条件化问答**）：
   - 最后在做什么 →「洗澡/冲凉」
   - （自动追问）放卫生间哪里 →「置物架/镜柜」
   - 最后在哪个房间 →「卫生间」（注意：**选项来自他的户型**，没有玄关）
   - 时段 →「晚上」；刚摘随手放 →「是」
4. 点「🧠 开始推理」→ 展示：🤖 大模型推理 → 最可能「浴室置物架/镜柜」+ 概率条 + 逐条依据（行为常识/追问/历史记录）
5. 说："它结合了常识（洗澡摘眼镜）、追问（置物架）、历史数据（你过去 10 次找回记录）"
6. 点「在这里找到了 ✓」→ 成功页 → 说"记录已入库，个人数据持续更新"

## 第 3 幕：数据可视化（2 分钟）
1. 点「📊 数据统计与分析」
2. 依次指：统计卡（成功率/平均用时）→ 智能洞察（"你最常丢在床头柜…"）→ 高频地点条形图 → 房间分布环图 → 30 天趋势 → 时段分布 → **🔥 户型热力**（房间着色，虚线=户型外房间）
3. 演示「⬇️ 导出数据」下载 JSON → 「⬆️ 导入数据」原样导回（提示条数）
4. 记录表：翻页、删除一条（统计实时更新）

## 第 4 幕：硬件端口（2 分钟）
1. 点「📡 硬件设备接入」：3 台模拟设备；**实时事件流自动刷新**（8 秒一条，页面是"活"的）
2. 点「📡 定位扫描」→ 定位器报告房间+距离；「🔊 呼唤」→ 蜂鸣应答；「🎲 模拟一次事件」
3. 「＋ 注册新设备」演示接入流程；指出页面底部的**接入协议**（真实硬件按此对接）
4. 联动演示：回「🔍 找眼镜」→ 推理到结果页 → 点「📡 定位器扫描」→「🔄 用设备结果重新推理」→ **推荐位置随定位信号改变**（强证据注入）

## 第 5 幕：画像联动（1 分钟）
1. 「🧠 个性化智能体」→ 给卧室添加自定义放置点「飘窗」→ 保存 → 户型预览更新
2. 重新推理「刚起床/卧室」场景 → 「飘窗」作为候选出现（自定义放置点参与推理）

## 收尾（30 秒）
"五个能力：多账户个性化、引导推理（大模型+常识回退）、数据库统计可视化、硬件接入端口、户型感知。零依赖、一条命令启动。谢谢！"

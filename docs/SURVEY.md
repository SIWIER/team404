## 一、问卷正文（可直接粘贴到问卷星）

```
找眼镜助手（帮您找回丢失眼镜的智能助手）需求调查问卷
（导语：本问卷匿名填写，约2分钟，数据仅用于课程项目研究，感谢支持！）

【基本信息】
1.您的年级是 [单选题] A.大一 B.大二 C.大三 D.大四及以上
2.您佩戴眼镜的情况是 [单选题] A.每天佩戴 B.偶尔佩戴 C.只有备用眼镜，平时基本不戴 D.不近视、不戴眼镜
3.您佩戴眼镜的时长是 [单选题] A.1年以内 B.1~3年 C.3~5年 D.5年以上

【丢失经历】
4.您平均多久会经历一次"找不到眼镜" [单选题] A.几乎每天 B.每周一两次 C.每月一两次 D.很少发生 E.从未发生过
5.您通常在什么情况下找不到眼镜 [多选题]（最多选3项）A.起床、睡前 B.洗漱、洗澡前后 C.换衣服、出门前 D.学习、工作间隙 E.运动、做家务后 F.其他
6.您的眼镜最常"藏"在哪里 [多选题]（最多选3项）A.床头柜、枕边 B.书桌、电脑桌 C.洗手台、浴室置物架 D.沙发缝隙、茶几 E.外套、裤子口袋 F.头顶上或衣领 G.书包、眼镜盒 H.其他
7.找不到眼镜时，您通常会怎么做 [多选题]（最多选3项）A.凭记忆挨个房间找 B.全家/全宿舍翻箱倒柜 C.喊人帮忙一起找 D.近视不深，凭手感摸索 E.干脆不找了（换隐形/备用眼镜）F.其他

【对"找眼镜助手"的态度】
8.如果有一个程序，通过几个问答帮您回忆、推理眼镜最可能在哪，您的使用意愿是 [量表题] 很不愿意/不愿意/一般/愿意/很愿意
9.该程序会记录您每次找回的位置，并统计出"您最常把眼镜丢在哪"，您觉得这对您有帮助吗 [量表题] 很没帮助/没帮助/一般/有帮助/很有帮助
10.请对以下功能的期待程度进行评价 [矩阵题]（很不期待/不期待/一般/期待/很期待）
    问答式引导推理找眼镜 / 个人找回数据统计与图表 / 家庭户型图辅助推理（按房间远近、路过房间加权）/ 多账户个性化智能体（每位家人各自画像）/ 硬件定位标签（贴在眼镜盒上，一键响铃）
11.请按您认为的实用程度，给以下功能排序（最实用→最不实用） [排序题] 问答式引导推理找眼镜 / 个人找回数据统计 / 硬件定位标签 / 个性化智能体画像
12.如果眼镜盒上贴一个小标签，手机点一下它就会响铃帮您循声寻找，您愿意使用吗 [单选题] A.非常愿意 B.愿意 C.看情况 D.不太愿意 E.不愿意
13.您能接受的"响铃标签"价格范围是 [单选题] A.10元以内 B.10~30元 C.30~60元 D.60~100元 E.只要好用，价格不是问题
14.该程序需要记录您的生活习惯、丢失位置等个人数据才能越来越准，您的接受程度是 [量表题] 很不接受/不接受/一般/接受/很接受
15.您更希望以哪种形式使用该程序 [单选题] A.微信小程序 B.网页 C.独立手机App D.都可以
16.关于"找眼镜助手"，您还有什么需求或建议 [简答题]
```

## 二、每题设计意图（答辩/分析用）

| 题号 | 支撑什么 |
|---|---|
| 1~3 | 受访者画像（年级/戴镜频率/时长） |
| 4~7 | **校准推理引擎知识库**：高频场景与高频位置排序（对应 `src/modules/reason/knowledge.js` 的 base 概率与行为加成） |
| 8~9 | 论证核心功能（引导推理、数据统计）的需求强度 |
| 10~11 | 五大功能**优先级排序**依据 |
| 12~13 | 硬件防丢标签的**接受度与定价**依据 |
| 14 | **隐私设计**依据（画像页要不要加"数据用途说明"） |
| 15 | 佐证**微信小程序**产品形态决策 |
| 16 | 开放建议，答辩"根据调研反馈迭代"素材 |

## 三、建议的跳题逻辑（问卷星设置）

- 第 2 题选 D → 跳到第 14 题（不戴眼镜者仍可评价隐私与形态）
- 第 4 题选 E → 跳到第 8 题

# 🧑‍💻 Vibe Coding 零基础入门指南

> 不会写代码也能干活：你负责"说人话 + 验收"，AI 负责写代码。
> 工作法只有四步循环：**描述 → 让 AI 改 → 跑测试 → 交给队长**。

---

## 一、开工前准备 4 样东西

1. **Node.js**（22.5 以上）：nodejs.org 下载安装；验证：Win+R → `cmd` → `node -v` 显示 v22/v24
2. **编辑器**：Visual Studio Code（免费）
3. **AI 助手**：任意会写代码的 AI（DeepSeek/豆包/ChatGPT……团队统一用一个最好）
4. **拿到代码**：
   - A. 有仓库地址：装 Git → 目标文件夹右键 "Git Bash Here" → `git clone 仓库地址`
   - B. 有压缩包：解压到**纯英文路径**文件夹（路径不要有中文和空格）

## 二、第一次跑起来（3 步）

1. 进入 `find-my-glasses-pro` 文件夹
2. 双击 `start.bat`（黑窗口是程序本体，**别关**）
3. 浏览器打开 `http://localhost:8081`，用 `xiaoming / 123456` 登录点一遍

卡住就把黑窗口红字发给队长，先别自己瞎折腾。

## 三、看懂目录（只记 5 行）

| 路径 | 是什么 | 能碰吗 |
|---|---|---|
| `server.js` | 程序总开关 | ❌ 别碰 |
| `src/core/` | 公共零件库 | ❌ 别碰 |
| `src/modules/` | 四大业务模块 | ✅ 只碰自己认领的 |
| `public/js/views/` | 网页页面（一文件一页） | ✅ 自己认领的页面 |
| `miniprogram/pages/` | 小程序页面（一文件夹一页） | ✅ 自己认领的页面 |

## 四、Vibe Coding 四步循环

1. **跑起来**：先看要改的页面现在长什么样
2. **描述**：把下面模板填好发给 AI，并粘贴相关代码
3. **让 AI 改**：把 AI 给的新代码替换进文件保存
4. **验收**：黑窗口 Ctrl+C 停止 → `node server.js` 重启 → 浏览器刷新看效果 → 另开 cmd 进项目目录 `node --test` → **pass 54 / fail 0** 才算过；fail 非 0 就把报错原样丢回给 AI
5. **提交**：用模板 4 让 AI 生成提交命令

## 六、红线（背下来）

1. 🔒 **`.env` 里的 API 密钥**：绝不粘贴给任何 AI、绝不发群、绝不提交 Git（当银行卡密码）
2. 提交前 `git status`，出现 `.env` 或 `data/` 先停下问队长
3. 不碰 `src/core/` 和 `server.js`；改别人的模块先打招呼
4. 每次改完必须 `node --test` 全绿
5. 提交信息写中文，写清楚改了什么

## 七、卡住自救顺序

1. 报错丢给 AI（模板 3）
2. 查 `docs/SDD.md` 第 4 节（接口）、`DEVELOPMENT.md` 第 8 节（常见坑）
3. 群里问队友，贴报错截图
4. 还不行：分支留好标记"求助"，换任务干（**严禁**瞎改 core、删数据库、乱提交）

## 八、验收清单（队长检查时对这条）

- [ ] 程序能跑，登录正常
- [ ] 我负责的页面/接口按要求工作
- [ ] `node --test` 全绿
- [ ] git 提交规范、没夹带私货
- [ ] 一句话能讲清我改了什么

# 🔖 硬件方向文档：UHF RFID 找眼镜方案（无实物设计版）

> 状态：**无实物设计**（尚无真实硬件）｜ 版本 v1 ｜ 更新 2026-08
> 关联代码：`src/modules/hardware/`、`src/modules/reason/engine.js`（无硬件补偿）、
> 画像 `hardware` 字段（注册时"有无设备"提问，见 SDD §5.2）

## 0. 一句话结论

眼镜本体太轻、放不下有源定位器 → **眼镜贴 UHF 无源抗金属标签**，靠**手持读取机**扫描找镜；
**眼镜盒保留有源定位器**（体积够放电池），负责"盒子+眼镜一起丢"的场景。

## 1. 产品场景分工

| 场景 | 硬件 | 交互 |
|---|---|---|
| 眼镜随手丢在家里某处 | UHF 无源标签（贴镜腿）+ 手持读取机 | 用户拿手持机逐房间扫描，读取机上报"哪个房间检测到 + 信号强度"→ 小程序显示方位指引 |
| 眼镜盒（连同眼镜）一起丢 | 眼镜盒定位器（现有 ESP32-C3 有源设备，已支持） | 定位上报房间 + 远程蜂鸣呼唤 |
| 没有硬件 | 无 | 问答式推理（引擎启用"无硬件补偿"，见 §4） |

**默认假设：用户没有手持机、也没有任何硬件设备**——小程序注册时询问"有无设备"，
未选任何设备时推理引擎强化行为/历史/偏好证据并锐化排名（见 `engine.js` 的 `noHardware` 补偿）。

## 2. 硬件设备需求清单（采购/自制目标规格）

### 2.1 UHF RFID 无源抗金属珠宝级标签（贴眼镜）★核心

| 项目 | 规格 |
|---|---|
| 协议 | ISO 18000-6C / EPC Gen2（UHF RFID 通行标准） |
| 频段 | 860-960 MHz（国内合规 920-925 MHz） |
| 形态 | **珠宝级小标签**（目标 ≤ 15×8 mm，越薄越好，可贴合镜腿内侧/桩头） |
| 抗金属 | 必须：镜腿常见金属/TR90/板材，金属会失谐 → 选**抗金属标签**（陶瓷/吸波材料基材） |
| 读取距离 | 配合手持机 ≥ 3 m（理想 5 m+，与手持机功率/天线相关） |
| 供电 | 无源（读卡器供能），无需电池、无需充电 |
| 参考成本 | 单价约 1~10 元（珠宝级/抗金属小尺寸溢价） |
| 安装注意 | 避开金属铰链；贴板材/TR90 镜腿或镜片侧缘效果最好 |

### 2.2 UHF RFID 手持读取机（**假设已获取**）

| 项目 | 规格 |
|---|---|
| 形态 | 成品手持机（优先）；可选 ESP32 + UHF 模组（PR9200 等）自研 |
| 协议 | EPC Gen2 读写；可编程上报 |
| 连接 | **蓝牙 BLE 或 WiFi 透传**到手机小程序（蓝牙优先，现场演示不依赖网络） |
| 上报内容 | `{ tag_epc, rssi_dbm, room(可选), ts }`——至少要有 EPC + RSSI |
| 参考成本 | 成品手持机 300~1500 元；自研模组约百元级（天线调试为主要工作量） |
| 演示建议 | 中期指导前用**成品手持机 + 蓝牙透传**最快出 demo |

### 2.3 眼镜盒定位器（复用现有，无需新采购）

现有 ESP32-C3 有源设备（定位上报 + 蜂鸣指令），设备类型 `locator`，产品定位从
"找眼镜"调整为"找眼镜盒（眼镜盒+眼镜一起丢）"。固件 v1 已就绪，待实机联调。

## 3. 与系统对接契约（预留，待实物接入时启用）

- **设备类型**：新增 `rfid_reader`（手持读取机，有源可下发指令）；标签不注册为设备，
  作为**被检测目标**由读取机事件携带（`tag_epc`）
- **事件**：`device_events` 新增 `rfid_detect` 事件：
  `{ device_id, ts, type: 'rfid_detect', payload: { tag_epc, rssi_dbm, room } }`
- **上行复用**：`POST /api/hardware/devices/{id}/report` 直接可用
- **实时推送**：现有 WebSocket `device_event` 通道直接复用，小程序 hardware 页可加"最近检测"面板
- **推理联动**：读取机检测事件 → `hardware.getLastHint()` → 注入 `facts.deviceHint`
  （引擎已支持：同房 ×6.0×面积因子、邻近连续衰减，见 SDD §5.1）

## 4. 无硬件补偿（已实现）

用户画像 `hardware` 为空且本次无定位提示时，推理引擎自动：

- 强化非硬件证据：同房间 ×1.8→2.1、时段卧室 ×1.4→1.5、历史每命中 ×0.5→0.6、
  偏好 ×1.35→1.5、路过房间 ×1.6→1.7
- 锐化排名：概率归一化幂次 γ=1.25，抬高头部置信度、给出更果断建议
- LLM 路径：提示词追加"用户没有硬件设备，请更充分利用行为/历史证据，结论可更果断"

## 6. 风险与备注

- **金属失谐**：标签必须抗金属款；镜腿材质决定贴附位置
- **方向性**：UHF 波束有方向，寻找 UX 需设计"冷热指示"（RSSI 强弱可视化）
- **隐私**：EPC 全局唯一，文档与答辩中说明"标签仅关联本人账号、离线不可追踪"
- **读取机成本**：团队预算优先买成品手持机；自研模组放二期
